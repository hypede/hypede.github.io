GNOME, reshaped into a Chrome OS–style desktop.

A shelf at the bottom, a bubble launcher and a status tray, running on an unmodified GNOME Shell. Settings built from real KDE modules. A file manager that mixes GNOME Files and COSMIC Files.

What's inside

Three parts, each built on something that already works.

HypeDE is a separate session next to your regular GNOME. Your login screen gets a new “HypeDE” entry; nothing in GNOME is patched or replaced.

Shell and launcher

GNOME Shell 48–50 · session mode · extension
  • The shelf holds GNOME's own indicators and sits at any screen edge, so every system indicator keeps working.
  • Pinned and running apps with a running dot; click to open, focus, minimise or cycle windows.
  • The launcher searches apps, settings and recent files, calculates 12*(3+4) and searches the web.
  • Quick settings and the calendar open upwards; notifications land in the bottom-right corner.

Settings with KDE inside

Qt 6 · QML · KCMUtils · GSettings
  • Chrome OS layout: search in the title bar, menu on the left, cards on the right.
  • Real KDE modules for network, Bluetooth, sound, printers, users, default apps and Flatpak, embedded in the page.
  • GNOME-side pages for mouse, keyboard, night light, power, wallpaper, theme and the shelf.
  • One theme: the KDE modules follow GNOME's light or dark style.

Files

Python · GTK 4 · libadwaita
  • From GNOME Files: sidebar, path bar, search and the selection bar.
  • From COSMIC Files: tabs and a details pane with previews.
  • Grid with thumbnails or list, rubber-band selection, drag and drop.
  • Background copy and move with progress, undo and trash restore.
Make it yours

Move the shelf, restyle the launcher, change almost everything.

Every part of the desktop has a setting in HypeDE Settings, and HypeDE keeps its settings apart from your regular GNOME session, so experimenting there never changes GNOME.

  • Shelf at the bottom, left, right or top
  • Full-width or floating shelf
  • Shelf size, icon size, opacity, blur
  • Bubble or full-screen launcher
  • Columns, icon size, order, hidden apps
  • What the launcher searches
  • Fonts, icons, cursor, window buttons
  • Animation speed and window animations
  • Corner rounding and menu opacity
  • Notification position
  • Resolution, refresh rate, display scale
  • Which GNOME services start
  • Backup and restore of the whole setup
Lock screen

Colour waves, a big clock and a password field that pops up.

When you lock the screen, waves in your accent colour roll over it and reveal the blurred wallpaper and the clock. Press a key: the clock moves up, the password field springs in and cards with battery and system load unfold beside it. Unlocking folds everything away.

How it works

Next to GNOME, not instead of it.

Its own session

A GNOME Shell session mode and gnome-session units start the shell as gnome-shell --mode=hypede. Defaults use :HypeDE sections, so they never touch your regular GNOME session.

KDE modules, embedded

Settings loads modules with KCModuleLoader, the same function kcmshell6 uses, so both QML and widget-based modules fit inside the page.

Its own configuration

The session runs with a separate dconf database, ~/.config/dconf/hypede. Layouts and accessibility come over from GNOME on first login; GNOME extensions stay out unless you allow them, and optional GNOME services start only if you switch them on.

Honest limits

KDE modules that configure KWin or PowerDevil would do nothing under GNOME, so those pages talk to GSettings instead. Monitor arrangement still opens GNOME Settings.

shell/modes/hypede.json      top bar → shelf, enabled extensions
shell/extension/…            shelf, launcher, overview, notifications
session/                     login-screen session, gnome-session units
apps/settings/               Settings: C++/QML, KCMUtils, GSettings, D-Bus
apps/files/                  Files: Python, GTK 4, libadwaita
Install

Arch Linux and CachyOS

Needs GNOME Shell 48–50. The build limits compile jobs to your free memory; force a value with JOBS=2 makepkg -si.

Build and install the package

git clone https://github.com/hypede/hypede
cd hypede/packaging
makepkg -si

Add the KDE modules you want

All optional. Without one, its row in Settings names the package to install.

sudo pacman -S plasma-nm bluedevil plasma-pa print-manager plasma-workspace \
               plasma-desktop kde-cli-tools flatpak-kcm kinfocenter power-profiles-daemon

Log out and pick “HypeDE”

The session appears on GDM, SDDM and other login screens that read /usr/share/wayland-sessions.

Other distributions: make && sudo make install, see the README for dependencies. Only want the shelf in regular GNOME? make install-user.

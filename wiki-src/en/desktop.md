# Desktop

## Icons

Files from your Desktop folder appear on the desktop, plus Home and Trash if you like. Drag them into
apps and back, double-click to open, right-click for the menu. Settings: *Personalization → Desktop*.

## Live wallpapers

*Personalization → Live wallpaper* has animated wallpapers (waves, bokeh, gradient) and **Video or
GIF…** for a file of your own. They pause when maximised windows cover the desktop, to save battery.
Speed is adjustable; Lite mode turns them off.

## Widgets

| Widget | Shows |
|---|---|
| Clock | time and date |
| Calendar | the month; arrows switch months |
| Weather | temperature and sky for the city chosen in GNOME Weather; click to open it |
| System | processor, memory and battery |
| Music | the song that is playing, with back, play and next; hidden when nothing plays |
| Note | a plain text note, saved as you type |

- **Add or remove** in *Personalization → Widgets*, or right-click any widget.
- **Move**: drag a widget anywhere; it snaps to an 8-pixel grid. *Return to the column* puts it back
  on the right edge.
- Widgets live under windows, like icons. Show the desktop with four fingers down to see them.

# Keys and gestures

## Keyboard

| Shortcut | Action |
|---|---|
| <kbd>Super</kbd> | open or close the launcher |
| <kbd>Super</kbd>+<kbd>S</kbd> | window overview |
| <kbd>Super</kbd>+<kbd>L</kbd> | lock the screen |
| <kbd>Super</kbd>+<kbd>1</kbd>…<kbd>9</kbd> | open the n-th app on the shelf |
| <kbd>Super</kbd>+<kbd>Space</kbd> | next keyboard layout |
| <kbd>Super</kbd>+<kbd>V</kbd> | clipboard history |
| <kbd>Super</kbd>+<kbd>Z</kbd> | float the window: small, on top of others; again to put it back |
| <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | reopen the window you just closed, in the same place |
| <kbd>Super</kbd>+<kbd>A</kbd> | ask the AI about the selected text |
| <kbd>Print Screen</kbd> | screenshot |

All of them can be changed in *Settings → Device → Keyboard shortcuts*. What <kbd>Super</kbd> opens
(launcher or overview) is in *Settings → Shelf and launcher*.

## Touchpad

| Gesture | Action |
|---|---|
| Four fingers up | open the launcher — or bring back windows hidden by the gesture below |
| Four fingers down | show the desktop: windows slide away and minimise |
| Three fingers up | window overview (GNOME) |
| Three fingers left or right | switch desks (GNOME) |

Gestures follow your fingers one-to-one. Let go before about a third of the way and everything goes
back. Four-finger gestures can be switched off in *Settings → Device → Touchpad*.

## Mouse

- Drag a window to a screen edge to snap it to half the screen, to the top to maximise.
- Right-click an app on the shelf for its windows and actions.
- Right-click a desktop widget to add, move back or remove widgets.

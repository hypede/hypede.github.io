# Клавиши и жесты

## Клавиатура

| Сочетание | Действие |
|---|---|
| <kbd>Super</kbd> | открыть или закрыть лаунчер |
| <kbd>Super</kbd>+<kbd>S</kbd> | обзор окон |
| <kbd>Super</kbd>+<kbd>L</kbd> | заблокировать экран |
| <kbd>Super</kbd>+<kbd>1</kbd>…<kbd>9</kbd> | открыть n-е приложение на полке |
| <kbd>Super</kbd>+<kbd>Space</kbd> | следующая раскладка |
| <kbd>Super</kbd>+<kbd>V</kbd> | история буфера обмена |
| <kbd>Super</kbd>+<kbd>Z</kbd> | плавающее окно: маленькое и поверх остальных; ещё раз — вернуть |
| <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | вернуть только что закрытое окно на прежнее место |
| <kbd>Super</kbd>+<kbd>A</kbd> | спросить ИИ о выделенном тексте |
| <kbd>Print Screen</kbd> | снимок экрана |

Все меняются в *Настройки → Устройство → Сочетания клавиш*. Что открывает <kbd>Super</kbd> (лаунчер
или обзор) — в *Настройки → Полка и лаунчер*.

## Сенсорная панель (тачпад)

| Жест | Действие |
|---|---|
| Четыре пальца вверх | лаунчер — или вернуть окна, убранные жестом вниз |
| Четыре пальца вниз | рабочий стол: окна разъезжаются и сворачиваются |
| Три пальца вверх | обзор окон (GNOME) |
| Три пальца влево или вправо | переключить рабочий стол (GNOME) |

Жесты идут за пальцами один к одному. Отпустите раньше трети пути — всё вернётся назад. Жесты четырьмя
пальцами отключаются в *Настройки → Устройство → Сенсорная панель*.

## Мышь

- Перетащите окно к краю экрана — оно займёт половину, к верхнему краю — развернётся.
- Правая кнопка по приложению на полке — его окна и действия.
- Правая кнопка по виджету — добавить, вернуть в столбик или убрать виджет.

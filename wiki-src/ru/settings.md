# Настройки

Одно окно для всего, устроенное как в Chrome OS: поиск сверху, разделы слева.

| Раздел | Что внутри |
|---|---|
| Сеть, Bluetooth | модули KDE (`plasma-nm`, `bluedevil`), прокси |
| Устройство | экраны, мышь, сенсорная панель, клавиатура и сочетания клавиш, звук и принтеры, питание, хранилище |
| Персонализация | темы, магазин тем, обои, живые обои, рабочий стол, виджеты, стиль, анимации |
| Полка и лаунчер | положение, вид, размер, что ищет лаунчер |
| Экран блокировки | вид часов, цвета, волны, карточки, обои, сообщение |
| Безопасность и конфиденциальность | история недавних файлов, защита |
| Приложения | установленные приложения, приложения по умолчанию, уведомления |
| ИИ-помощник | провайдер и вход |
| Специальные возможности | размер текста, контраст, лупа, экранный диктор |
| Системные настройки | дата и время, языки, заставка загрузки, оборудование, учётные записи, службы GNOME, режимы фокуса, сеанс, автозапуск, конфигурация HypeDE |

## Поиск

Пишите в поле сверху: находятся и разделы, и отдельные настройки, по-русски и по-английски.

## Резервная копия

*Системные настройки → Конфигурация HypeDE* сохраняет все настройки HypeDE в файл и восстанавливает их.
Настройки HypeDE лежат в своей базе, `~/.config/dconf/hypede`, отдельно от обычного GNOME.

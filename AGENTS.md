# Сайт HypeDE: заметки для ИИ-агентов

С пользователем говорите по-русски. Сообщения коммитов — на английском.

Это сайт hypede.xyz: статичный HTML, который GitHub Pages раздаёт из
`main`. Что где лежит — в `README.md`. Код самого HypeDE находится в
репозитории разработки, общие заметки для агентов — в его `AGENTS.md`.
Публичная версия — `hypede/hypede`.

- **Главная** — `index.html` и `ru/index.html`, стили и скрипты в
  `assets/site.css` и `assets/site.js`.
- **Демо в браузере** — `try/` и `ru/try/`, код в `assets/try/demo.js` и
  `demo.css`. Это упрощённая копия рабочего стола: полка, лаунчер с
  калькулятором, быстрые настройки, окна, «Файлы», «Терминал»,
  «Настройки». Что браузер сделать не может, открывает окно «Установите
  полную версию» (функция `full()` в `demo.js`).
  - Строки демо лежат в объекте `STRINGS` (en и ru) внутри `demo.js`.
  - Значки демо собираются из репозитория HypeDE:
    `python3 tools/build-try-icons.py ../hypede`
    (путь к любой копии репозитория HypeDE).
- **Вики** — Markdown в `wiki-src/en` и `wiki-src/ru`. Сборка:
  `pip install markdown`, затем `python3 tools/build-wiki.py`. Скрипт
  заодно проставляет версии `?v=` файлам сайта и демо, чтобы браузер не
  показывал старую копию.
- **Проверка.** Запустите `python3 -m http.server`, откройте страницу в
  браузере (например, через Playwright) и убедитесь, что в консоли нет
  ошибок, а на ширине телефона нет горизонтальной прокрутки.
